# AiKasya

AiKasya's repository keeps frontend and backend work separate.

- `front end/` contains the React, TypeScript, and Vite app, its assets, configuration, and browser tests.
- Backend teammates can add their service in a separate top-level folder such as `backend/`.

## Run the frontend

```sh
cd "front end"
npm install
npm run dev
```

## Verify the frontend

Run these commands inside `front end`:

```sh
npm run build
npm test
```

See [the frontend README](front%20end/README.md) for features, offline support, and additional setup instructions.
